PENYEMPURNAAN SCAN OCR - REMINDER USG

File dalam paket:
- reminder.js: OCR multi-tahap, praproses foto, pemetaan singkatan pemeriksaan, pengisian otomatis ke kolom input pasien yang sama.
- index.html: pembaruan versi cache agar browser memuat JavaScript/CSS terbaru.
- ui.css: stylesheet Reminder USG (dipertahankan).

Peningkatan pembacaan:
1. Foto asli dibaca terlebih dahulu, kemudian foto versi diperbesar dan ditingkatkan kontrasnya dibaca sebagai percobaan kedua bila hasil pertama belum cukup lengkap.
2. Pemetaan istilah pemeriksaan mengenali variasi seperti USG abd, abd, abdn, abdomen -> ABDOMEN FULL; uro/partial -> PARTIAL / URO; mammae/mamae/payudara -> MAMMAE; colli/leher/tiroid -> COLLI / LEHER; serta variasi Doppler.
3. Nomor WhatsApp dibaca dari baris berlabel No. WA/WhatsApp/Telepon/HP dan dinormalisasi oleh validasi yang sudah ada.
4. Dokter pemeriksa/radiologi dicocokkan dengan pilihan dokter yang tersedia pada aplikasi. Bila nama dokter tidak cocok dengan daftar pilihan, kolom dokter dibiarkan kosong agar dipilih manual.
5. Hasil scan mengisi langsung baris formulir manual yang sama. Semua kolom tetap bisa diedit, lalu gunakan tombol Kirim WA + Simpan seperti biasa.
6. Pesan status memberi tahu data utama yang belum terbaca agar petugas melengkapinya.

Pemasangan:
1. Cadangkan file lama terlebih dahulu.
2. Ganti reminder.js, ui.css, dan index.html pada folder modul sesuai struktur repository.
3. Commit/push ke GitHub Pages.
4. Buka website dan lakukan hard refresh atau bersihkan cache bila perlu.

PENTING - BATASAN AKURASI:
OCR Tesseract berbasis browser bukan model khusus tulisan tangan. Peningkatan kontras dan pembacaan ulang dapat membantu, tetapi tidak menjamin semua tulisan tangan terbaca benar. Nama dan nomor WhatsApp, dokter pemeriksa/radiologi, serta jenis USG wajib diperiksa petugas sebelum tombol Kirim WA + Simpan ditekan. Nomor RM, klinis, tanggal registrasi, dan dokter pengirim belum dimasukkan karena formulir Reminder saat ini tidak memiliki kolom untuk menyimpannya. Foto diproses di browser; library OCR diunduh dari CDN dan memerlukan koneksi internet.
